# API Documentation Testing Checklist

## Spec Accuracy
- [ ] Paths match implementation.
- [ ] Methods (GET/POST/PUT/DELETE) correct.
- [ ] Params: required/optional, types, constraints.
- [ ] Schemas: fields, nesting, enums.

## Examples
- [ ] cURL works (copy-pasteable).
- [ ] Request/response JSON valid.
- [ ] Auth headers shown.
- [ ] Error samples (400, 401, 404, 500) present.

## Usability
- [ ] Quickstart gets dev to "Hello World" in <5 min.
- [ ] No broken internal links.
- [ ] Glossary/abbreviations explained.

## Webhooks (if applicable)
- [ ] Event types listed.
- [ ] Payload schema + sample.
- [ ] Retry/backoff & signature verification explained.

## Localization
- [ ] Key terms consistent in EN/RU.
- [ ] Code blocks NOT translated.
