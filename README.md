# Technical Writing Portfolio

REST API / OpenAPI Documentation Portfolio

**Role:** Senior Technical Writer  
**Focus:** REST API · OpenAPI 3.x · Developer Documentation · Docs-as-Code · Bilingual (EN/RU)

## 📌 Overview

A demonstration portfolio documenting a fictional Orders API from scratch — built to showcase real-world API documentation practices for developers and integrators.

## 🎯 What this portfolio demonstrates

- API Reference design & Information Architecture
- OpenAPI 3.1 specification authoring
- REST API documentation (endpoints, params, schemas)
- Request/response examples & Error handling
- Webhooks & event payloads
- Developer onboarding guides
- Docs-as-Code & Git-based workflows
- CI validation mindset
- English/Russian localization

## 📂 Repository Structure

## 🛠 Tech Stack

`REST API` · `OpenAPI 3.1` · `JSON/YAML` · `Markdown` · `Git` · `Postman/cURL` · `GitHub Actions`

## 🧠 Approach

- **Single Source of Truth**: spec-driven documentation (OpenAPI as source).
- **Docs-as-Code**: sources in Git, versioned with changelog, reviewed via PR.
- **Developer-first**: copy-pasteable request/response examples, clear error states.
- **Bilingual**: EN (default) + RU (`README.ru.md`) for broader reach.

## ⚠️ Project Context

⚠️ The Orders API is illustrative/simulated. The documentation demonstrates how I structure, validate, and maintain API docs for real engineering teams (validation checklist, schema consistency, clear error handling).
